# 📂 포트폴리오 메이커

> 내 프로젝트 경험을 입력하면, **목표 직무에 어울리는 색과 디자인의 PPT 포트폴리오**로 만들어 주는 웹 기능

이 레포지토리는 5인 팀 프로젝트 **「자기 계발 서비스」** 웹사이트 중 **포트폴리오 메뉴**를 맡아 구현한 결과물입니다.
완성된 기능은 팀의 홈 담당이 메인 사이트에 통합합니다.

<br>

## 💡 개발 배경

- 취업이나 지원을 준비할 때 포트폴리오는 꼭 필요하지만, **내용 정리와 디자인에 시간이 많이 듭니다.**
- 직무마다 어울리는 분위기가 다른데(예: 개발 / 디자인 / 기획), 이걸 매번 직접 맞추기는 어렵습니다.
- 그래서 **프로젝트 내용만 입력하면, 목표 직무에 맞는 디자인이 적용된 PPT를 자동으로 만들어 주는 기능**을 기획했습니다.

<br>

## ✨ 주요 기능

| 페이지 | 기능 |
|---|---|
| `index.html` | 포트폴리오 메인 화면 — 내 프로젝트 목록을 확인하고 추가·수정 |
| `star.html` | 프로젝트 경험을 **STAR 기법**(상황 Situation · 과제 Task · 행동 Action · 결과 Result)으로 정리 
| `export.html` | **목표 직무 선택 → 직무별 색상·디자인 테마 적용 → PPT 파일로 내보내기** |

<br>

<br>

## 📁 폴더 구조

```
portfolio/
├── index.html              # 포트폴리오 메인 (프로젝트 목록)
├── star.html               # STAR 기법 경험 정리
├── export.html             # 직무별 테마 선택 및 PPT 내보내기
├── css/
│   └── portfolio.css       # 포트폴리오 메뉴 전체 스타일
└── js/
    ├── portfolio-common.js # 페이지 공통 함수 (데이터 저장·불러오기 등)
    ├── projects.js         # 프로젝트 입력·목록 기능
    ├── star.js             # STAR 정리 기능
    └── export.js           # 직무별 테마 적용 및 PPT 생성
```

## ▶️ 실행 방법

### 방법 1. 내 컴퓨터에서 실행
```bash
git clone https://github.com/깃허브아이디/레포이름.git
```
1. 받은 폴더에서 `portfolio/index.html`을 브라우저(Chrome 권장)로 엽니다.
2. VS Code를 쓴다면 **Live Server** 확장으로 `index.html`을 실행해도 됩니다.

<br>

## 📝 사용 방법

1. **메인 화면**에서 내 프로젝트를 추가합니다.
2. **STAR 정리** 페이지에서 프로젝트 경험을 상황·과제·행동·결과로 나눠 작성합니다.
3. **내보내기** 페이지에서 목표 직무를 선택하면, 직무에 어울리는 색상과 디자인이 미리보기로 적용됩니다.
4. **PPT 다운로드** 버튼을 눌러 완성된 포트폴리오를 저장합니다.

<br>

## 🎨 디자인 규칙 (팀 공통)

- 폰트: **Pretendard**
- 색상: **흰 바탕 + 파란색 포인트**
- 팀원 5명이 각자 메뉴를 개발한 뒤 하나의 사이트로 합치기 때문에, 폰트와 색상을 통일했습니다.
